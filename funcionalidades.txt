Funcionalidades To-Do-App

Utilizadores

-login (feito)
-logout (feito) 
-criar conta (feito)
-editar conta(foto etc, etc) (feito)
-cada utilizador deve ter uma tag unica para identificar cada um (feito)
-estado online para o user (feito)

Projetos

-Criar projeto (feito)
-Editar projeto 
-Eliminar projeto (feito)
-Visão geral das tarefas e navegação pelo projeto
-Enviar convites para membros(feito)
-Atribuir permissões a outros membros(feito)
-visualização dos participantes do projeto(feito)
-Criador do projeto pode remover participantes, atribuir permissoes, eliminar projeto(feito)

Tarefas

-Criar Tarefa
-Subtarefas
-Estados
-prioridades e datas limite
-comentários
-Drag and drop no Kanban com as devidas permissoes
-FIltros de pesquisa

Convites

-Visualização de convites(feito)
-Aceitar/recusar convites(feito)
